# MyBUS 我的公車時刻表｜v0.50b
日期：2026-09-19

## 一、架構
v0.50b 從單頁面（面板切換）改成三頁式：
- `index.html`：首頁，搜尋站牌／路線＋路線分類快速輸入
- `nearby.html`：附近站牌
- `favorites.html`：常用站牌

## 二、Worker 端點

**`/live` 的關鍵處理**：

- 依 `Direction` 值合併重複的去程／返程記錄，避免同方向重複出現
- 依 `RouteUID`＋營運業者名稱排除「區公所」經營的社區接駁新巴士，解決同一路線名稱被幹線公車與社區巴士共用、資料互相污染的問題（例如 919 vs F919 的撞名）

**`/route-category` 對照表**：391 筆，涵蓋 10 個官方業務分類（捷運先導公車、幹線專車、內科專車、南軟專車、其他、跳蛙、F新巴士、輕軌接駁公車、觀光巴士、活動專車），每一筆都逐一比對過 TDX 官方路線清單，標註正確的 `city`（臺北市／新北市無法從路線名稱本身判斷，需要查表）。這是官方網站自己維護的業務分類，TDX 開放資料本身沒有這個欄位，只能人工整理、定期回頭比對官網更新。

## 三、搜尋與分類

- 搜尋框同時比對站牌名稱與路線名稱，臺／台等字差異已正規化處理
- 路線分類快速輸入分三種機制：
  - **直接列出清單**（幹線、先導、跳蛙、其他、新巴士F、輕軌）：打 `/route-category`，符合分類文字的路線排前面、看不出關聯的純數字路線排後面，每張卡片帶分類小標籤
  - **合併清單**（通勤＝內科＋南軟專車；其他＝其他＋觀光巴士＋活動專車）：一次列出多個分類，不需要多一層子選單
  - **文字提示**（小、市民小巴）：這兩類路線名稱本身規律到直接搜尋文字就找得到，不需要對照表；顏色字頭（藍紅綠棕橘）也是同樣邏輯，屬於路線編號本身的規律


## 四、路線詳情頁
- 改用 `/live` 一次拿到站序、到站時間、車輛位置，不再自己組合多支 API
- 單一方向的循環路線（例如 F915、懷恩專車）不顯示切換介面，直接標示「單一方向循環路線」
- 有去程／返程兩個方向的路線，改成箭頭切換（‹ 去程 ›），取代原本一格一格的分頁框線



# MyBUS  v0.50a 修改說明

## 已修改
- 首頁標題改為「MyBUS 找公車」。
- 功能說明改為「查詢公車到站時間」。
- 「路線分類快速輸入」最後加入「清除」按鈕。
- 清除按鈕會取消分類、清空路線輸入、清除搜尋結果並回到初始狀態。
- 「其他特殊路線」增加觀光、花季、假日、活動專車、兒童樂園、停車場接駁、懷恩及其他接駁。

- 路線站序頁將路線名稱與「沿途站名」分成不同區塊。
- 沿途站名加入站序節點與垂直時間軸。
- 到站狀態補充分辨「尚未發車」、「末班已過」、「暫不停靠」與即時資料異常。

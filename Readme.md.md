# MyBUS 我的公車時刻表｜v0.50b 版本說明

日期：2026-09-19
對應 GitHub：`macsire/bus`（`index.html`、`nearby.html`、`favorites.html`、`app.js`、`styles_a.css`）
對應 Cloudflare Worker：`b-proxy.biscuit-trove0d.workers.dev`（`worker.js`）

## 一、架構

v0.50b 從單頁面（面板切換）改成三頁式：

- `index.html`：首頁，搜尋站牌／路線＋路線分類快速輸入
- `nearby.html`：附近站牌
- `favorites.html`：我的常用

三頁共用同一份 `app.js`、`styles_a.css`，資料一律經由 Cloudflare Worker 介接 TDX，不直接呼叫 TDX API，金鑰不出現在前端。

## 二、Worker 端點

| 端點 | 用途 | 快取 |
|---|---|---|
| `/eta` | 預估到站（單路線或整縣市） | 短（10 秒） |
| `/route` | 路線清單／搜尋 | 長（一天） |
| `/stop` | 單路線站序（StopOfRoute） | 長 |
| `/stops` | 全市站牌主檔＋座標，供附近站牌與站名搜尋 | 長 |
| `/version` | 資料版本 | 短 |
| `/live` | 站序＋預估到站＋即時車輛位置（A2）合併結果，取代原本規劃要爬 ebus.gov.taipei 的作法 | 依內部呼叫各自快取 |
| `/route-category` | 官方業務分類對照表查詢 | 無（純查表，資料量小） |

**`/live` 的關鍵處理**：

- 依 `Direction` 值合併重複的去程／返程記錄，避免同方向重複出現
- 依 `RouteUID`＋營運業者名稱排除「區公所」經營的社區接駁新巴士，解決同一路線名稱被幹線公車與社區巴士共用、資料互相污染的問題（例如 919 vs F919 的撞名）

**`/route-category` 對照表**：391 筆，涵蓋 10 個官方業務分類（捷運先導公車、幹線專車、內科專車、南軟專車、其他、跳蛙、F新巴士、輕軌接駁公車、觀光巴士、活動專車），每一筆都逐一比對過 TDX 官方路線清單，標註正確的 `city`（臺北市／新北市無法從路線名稱本身判斷，需要查表）。這是官方網站自己維護的業務分類，TDX 開放資料本身沒有這個欄位，只能人工整理、定期回頭比對官網更新。

## 三、搜尋與分類

- 搜尋框同時比對站牌名稱與路線名稱，臺／台等字差異已正規化處理
- 路線分類快速輸入分三種機制：
  - **直接列出清單**（幹線、先導、跳蛙、其他、新巴士F、輕軌）：打 `/route-category`，符合分類文字的路線排前面、看不出關聯的純數字路線排後面，每張卡片帶分類小標籤
  - **合併清單**（通勤＝內科＋南軟專車；其他＝其他＋觀光巴士＋活動專車）：一次列出多個分類，不需要多一層子選單
  - **文字提示**（小、市民小巴）：這兩類路線名稱本身規律到直接搜尋文字就找得到，不需要對照表；顏色字頭（藍紅綠棕橘）也是同樣邏輯，屬於路線編號本身的規律
- 拿掉了原本會誤導使用者的「668 ↔ 668去程半」這類把路線支線名稱誤當成起訖站顯示的寫法

## 四、路線詳情頁

- 改用 `/live` 一次拿到站序、到站時間、車輛位置，不再自己組合多支 API
- 單一方向的循環路線（例如 F915、懷恩專車）不顯示切換介面，直接標示「單一方向循環路線」
- 有去程／返程兩個方向的路線，改成箭頭切換（‹ 去程 ›），取代原本一格一格的分頁框線
- 車號只在「即將到站」那一刻顯示，其餘距離只顯示倒數分鐘，避免跟「尚未發車」同時出現造成矛盾
- 到站狀態只有 3 分鐘內才加粗，站名只有在使用者的常用收藏裡才加粗，不是整排都同一個字重

## 五、拿掉的功能

- 捷運轉乘：整個移除，不串接 Metro／Rail API
- 設定到站提醒：原本是假功能（只存資料、沒有任何通知機制），已完全移除
- 原本 4 筆手動維護的 `LOCAL_ROUTE_INDEX` 別名清單：被更完整、驗證過的 `/route-category` 取代

## 六、視覺與版面

- 配色改用 Deep Ocean Blue／Verdant Forest Green／Sky Blue／Granite Gray／Off-White 為框架與選單文字色，路線分類色與到站狀態色維持獨立系統
- 候車點清單的到站時間改成圓形徽章（參考公車雷達的資訊分級：到站時間最搶眼、車號最不打擾）
- 首頁拆成三張獨立卡片（搜尋框／分類按鈕／附近站牌·我的常用捷徑），不再是一路往下疊的同一個框
- 結果清單改成單一外框＋分隔線，不是每一列各自一個方框；載入中的提示文字也不會被框住
- 品牌名稱「MyBUS 找公車」改為淺灰小字，讓卡片內的「查詢公車即時動態」成為視覺焦點

## 七、已知待辦

- 「快速」「夜間」分類目前確認為純數字或 `XX副` 這類已可被文字搜尋涵蓋的路線，暫不建對照表
- 路線分類色（藍紅綠棕橘）的最終配色與加粗規則尚未定案
